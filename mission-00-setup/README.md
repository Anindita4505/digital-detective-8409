# Mission 0 — Repository Setup

## 1. Task / Objective :-

The objective of this mission is to create and organize a GitHub repository for the Digital Detective Diwali Independent Learning Assignment.

The repository must have a structured folder system for all nine missions, along with README files to document the work completed in each mission.

## 2. Work Completed :-

- Created the project directory named 'digital-detective-8409'.
- Created separate directories for Missions 0 to 8.
- Created an 'evidence' directory for storing supporting screenshots.
- Created the root 'README.md'.
- Created README files for each mission.
- Created the required 'number_converter.py' file in the Mission 5 directory.
- Created a '.gitignore' file to exclude macOS '.DS_Store' files.

## 4. My Understanding :-

A repository is a project directory managed by Git, which helps track changes and maintain a history of the work.

A README file provides information about the project and its organization. Separate mission folders make the assignment easier to navigate and maintain.

The '.gitignore' file specifies files that Git should ignore, such as '.DS_Store', which is generated by macOS.

## 5. Difficulties Faced :-

- Understanding the correct repository structure.
- Separating the assignment directory from an existing Git repository on the Desktop.
- Understanding the purpose of '.gitignore' and Markdown formatting.

## 6. How I Resolved Them :-

- Verified the assignment directory's location and Git status without modifying the existing Desktop repository.
- Created the required directory structure using 'mkdir -p'.
- Used 'find' to verify the folders and files.
- Added '.DS_Store' to '.gitignore'.
- Used Markdown headings and tables to organize the root README.
