# Mission 0 — Repository Setup

## 1. Task / Objective

The objective of this mission was to create and organize a GitHub repository for the Digital Detective Diwali Independent Learning Assignment.

The repository required a structured folder system for all nine missions, along with README files to document the work completed in each mission.

## 2. Work Completed

- Created the project directory named `digital-detective-8409`.
- Created separate directories for Missions 0 to 8.
- Created an `evidence` directory for storing supporting screenshots.
- Created the root `README.md`.
- Created README files for each mission.
- Created the required `number_converter.py` file in the Mission 5 directory.
- Created a public GitHub repository with the same project name.
- Initialized Git in the local project directory.
- Renamed the initial branch from `master` to `main`.

## 3. Commands / Tools Used

### Commands Used

- `cd` — to navigate between directories.
- `pwd` — to verify the current working directory.
- `mkdir` — to create the mission directories.
- `touch` — to create empty files.
- `ls` — to list directory contents.
- `ls -R` — to inspect the project structure recursively.
- `find` — to locate and inspect README files.
- `cat` — to display file contents.
- `git init` — to initialize a Git repository.
- `git branch -m main` — to rename the initial branch to `main`.
- `git status` — to inspect the repository status.

## 4. My Understanding

A repository is a project directory managed by Git, which helps track changes and maintain a history of the work.

A README file provides information about the project and its organization. Separate mission folders make the assignment easier to navigate and maintain because the work for each topic stays organized in its own location.

## 5. Difficulties Faced

- Understanding the correct repository structure.
- Separating the assignment directory from an existing Git repository on the Desktop.

## 6. How I Resolved Them

- Verified the assignment directory's location and Git status without modifying the existing Desktop repository.
- Created the required directory structure using `mkdir`.
- Used `ls -R` and `find` to verify the folders and files.
- Used Markdown headings, lists and tables to organize the root README.
