### Task 4.2 — Understand Compilers and Interpreters

A compiler translates source code into another form, often machine code, before the program is executed. An interpreter executes a program through an interpreter, processing its instructions as the program runs. A compiler is commonly used with languages like C, while Python uses an interpreter along with a bytecode compilation step.

| Compiler                                                                        | Interpreter                                                                             |
| ------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| Translates source code into another form, often machine code, before execution. | Executes a program through an interpreter, processing instructions as the program runs. |
| Compiled programs can run without the original compiler.                        | The interpreter is generally needed to run the program.                                 |
| Example: C compiler.                                                            | Example: Python interpreter.                                                            |
