# Mission 1 — Know Your Computer

### Task 1.1 — IPOS: Typing and Saving a Document

| Stage      | What happens?                                                                | Hardware/component |
| ---------- | ---------------------------------------------------------------------------- | ------------------ |
| Input      | The user types text using the keyboard.                                      | Keyboard           |
| Processing | The CPU processes instructions, while RAM temporarily holds the active data. | CPU and RAM        |
| Output     | The typed document is displayed on the screen.                               | Monitor            |
| Storage    | The document is saved for future access.                                     | SSD / Hard Disk    |

**Explanation:**

When a user types a document, the keyboard sends input to the computer. The CPU processes the instructions, and RAM temporarily holds the working data. The monitor displays the document. When the user saves it, the file is stored on a storage device such as an SSD.

The overall flow is:

**Input → Processing → Output → Storage**
